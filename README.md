# ProjectBranchTracking

The merged application uses BenVersion as its base and includes AlecVersion's AI
strategy tree as an additional dataset.

Open [the merged app](ProjectBranchTracking-BenVersion/ProjectBranchTracking/tree.html)
in your browser. No build or server is required. In Settings, choose **Program dataset**
to switch between **DDB delivery program** (default) and **AI strategy pillars**.

Edits stay separate while switching in the same tab. Export JSON before refreshing
or closing the page to keep changes. Import/export applies to the selected dataset.

See [the gap analysis](GAP_ANALYSIS.md) for the feature comparison, implementation
choices and regression test instructions. AlecVersion remains the source reference.
